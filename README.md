
# CREEM DataFast Bridge

Connect CREEM payment events to DataFast analytics with TypeScript.

## Features

- TypeScript interfaces for payment data
- Track successful payments
- Send purchase events to DataFast
- Skip payments that are not marked as paid

## Installation

Install the package after it is published:

npm install creem-datafast-bridge

## Development

This package is currently under development.

Before using it with real payments, configure CREEM webhooks, verify webhook signatures, and confirm the supported DataFast event API.
